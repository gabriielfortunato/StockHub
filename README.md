# 📦 StockHub

Sistema de gerenciamento de estoque para pequenos negócios.

## 🚀 Objetivo

O StockHub é uma aplicação desenvolvida para facilitar o controle de estoque de pequenos comércios, permitindo cadastrar produtos, controlar entradas e saídas e acompanhar o inventário.

- Python
- Git
- GitHub
